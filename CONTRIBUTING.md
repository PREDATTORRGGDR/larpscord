# Участие в разработке Larpscord

Спасибо за интерес к проекту!

## Как внести вклад

1. Сделайте форк и ветку: `git checkout -b feature/моё-улучшение`.
2. Убедитесь, что сборка чистая:
   ```bash
   npm run lint
   cd src-tauri && cargo test
   ```
3. Коммиты — на русском или английском, в императиве: «Добавить…», «Fix…».
4. Откройте Pull Request с описанием, что изменено и зачем.

## Соглашения

- **Язык**: интерфейс и документация — русские; идентификаторы кода — английские.
- **Стиль Rust**: стандартный `rustfmt`, ошибки обрабатываются явно
  (никаких `unwrap()` в рабочем коде вне тестов).
- **Стиль TS/React**: strict-режим tsc, функциональные компоненты,
  zustand для глобального состояния, CSS-классы по БЭМ-подобной схеме.
- **Дизайн**: соблюдайте дизайн-систему Black Liquid Glass
  (см. `src/styles/design-tokens.css`).

## Чего мы не принимаем

- Заглушки вместо функциональности.
- Изменения, ломающие совместимость хранилища без миграции.
- Сбор учётных данных Discord (токены, пароли) — проект работает только
  через официальный локальный RPC.
