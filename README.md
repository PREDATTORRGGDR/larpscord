# Larpscord

**Студия настройки Discord Rich Presence.** Создавайте персональные статусы
активности в Discord — текст, картинки, кнопки, таймеры и музыка — в тёмном
интерфейсе уровня коммерческого продукта.

> Философия: **Установил → Открыл → Настроил → Применил.**
> Никаких Application ID, порталов разработчиков и конфигов.

## Возможности

- **Нулевая настройка Discord** — Larpscord сам находит запущенный Discord
  (Stable / PTB / Canary) и подключается по официальному локальному RPC.
- **Полный редактор Rich Presence** — тип активности (Играет / Транслирует /
  Слушает / Смотрит / Соревнуется), имя приложения, детали, состояние.
- **Картинки по URL** — Discord автоматически проксирует внешние изображения;
  подсказки (tooltip) для больших и маленьких картинок.
- **Таймеры** — «прошло» или «осталось» с живым отсчётом.
- **Кнопки** — до двух ссылок с валидацией.
- **Живой предпросмотр** — карточка, неотличимая от Discord-профиля.
- **Автоподключение и автореконнект** — Discord перезапустился? Активность
  вернётся сама.
- **Автосохранение, undo/redo, горячие клавиши** (Ctrl+Z, Ctrl+Enter).
- **Пресеты** — Игры, Музыка, Разработка, Кино, Работа, Минимал.
- **Профили** — быстрый доступ к черновику, последней и активной активности.
- **Музыкальный режим** — статус «Слушает» с треком, исполнителем и обложкой.
- **Настройки** — свой Application ID (опционально), автозапуск, трей.

## Установка (Windows 10/11)

1. Запустите `Larpscord_1.0.0_x64-setup.exe` из
   [релизов](https://github.com/) (или соберите сами — см. ниже).
2. Установщик потребует права только текущего пользователя — без UAC.
3. На рабочем столе появится ярлык **Larpscord**.
4. Откройте — при запущенном Discord статус в сайдбаре станет зелёным.

## Использование

1. Откройте Larpscord (Discord должен быть запущен).
2. Заполните поля в редакторе — предпросмотр справа обновляется мгновенно.
3. Нажмите **«Применить в Discord»** — статус появится в вашем профиле.
4. **«Сбросить»** — убрать активность.

## Как работает подключение к Discord

Larpscord использует официальный протокол Discord RPC через локальные
именованные пайпы Windows (`\\.\pipe\discord-ipc-0..9`):

- рукопожатие с встроенным Application ID;
- `SET_ACTIVITY` для публикации активности;
- PING/PONG keepalive и автоматическое переподключение.

Приложение **не собирает** пароли, токены и cookies — только локальный
RPC-канал, который Discord предоставляет сам.

Подробнее — в [docs/RESEARCH.md](docs/RESEARCH.md) (включая результаты
живых проверок протокола).

## Архитектура

Tauri 2 (Rust-бэкенд + React/TypeScript-фронтенд). Полное описание — в
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

```
src/          — React-фронтенд (редактор, музыка, пресеты, настройки)
src-tauri/    — Rust-бэкенд (Discord IPC/RPC, хранилище, пресеты)
docs/         — документация
scripts/      — генерация иконок
```

## Известные ограничения

- Картинки указываются https-ссылкой (Discord не принимает локальные файлы);
  свои ассеты — при использовании своего Application ID.
- CUSTOM-статус (тип 4) через RPC не устанавливается — ограничение Discord.
- Доступно максимум 2 кнопки — лимит протокола Discord.
- Автоопределение играющей музыки (Windows Media Session) — в разработке.
