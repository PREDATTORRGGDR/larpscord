# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/), версионирование SemVer.

## [1.1.0] — 2026-11-22

### Добавлено
- **Автоопределение музыки (SMTC)**: любой плеер (Spotify, SoundCloud в браузере,
  YouTube Music, Яндекс Музыка, VLC…) — название, исполнитель, альбом,
  позиция/длительность и статус паузы подхватываются автоматически.
- **Обложки в Discord**: обложка трека из медиа-сессии загружается на
  catbox.moe (кэш 6 часов) и показывается в активности.
- **Кнопка «Слушать»** в авто-режиме — поиск текущего трека в SoundCloud.
- Пользовательские пресеты: создание из черновика, удаление, импорт/экспорт JSON.
- Панель текущего трека в разделе «Музыка» с обложкой и прогрессом.

## [1.0.0] — 2026-11-22 (MVP)

### Добавлено
- Автоматическое обнаружение Discord (Stable/PTB/Canary) и подключение по RPC
  без какой-либо настройки.
- Редактор Rich Presence: тип активности, имя приложения, детали, состояние,
  timestamps (прошло/осталось), картинки по URL с tooltip-ами, до 2 кнопок.
- Живой предпросмотр карточки Discord с реалистичной имитацией профиля.
- Применение и сброс активности; авто-восстановление после реконнекта Discord.
- Автосохранение черновика, undo/redo (Ctrl+Z / Ctrl+Shift+Z), Ctrl+Enter — применить.
- Музыкальный режим (ручной): «Слушает» с треком/исполнителем/обложкой.
- Встроенные пресеты (Игры, Музыка, Разработка, Кино, Работа, Минимал).
- Профили: черновик / последняя / активная активности.
- Настройки: автоподключение, восстановление активности, свой Application ID,
  автозапуск, трей, каталог данных.
- Локальное хранилище JSON с атомарной записью, бэкапом и миграциями.
- Тосты, валидация лимитов Discord, индикатор статуса подключения.
- Установщик NSIS (установка для текущего пользователя) и ярлык на рабочем столе.

### Техническое
- Протокол Discord RPC проверен эмпирически (см. docs/RESEARCH.md):
  фрейминг, READY, SET_ACTIVITY, очистка через `activity: null`,
  PING/PONG keepalive, проксирование внешних картинок.
- 12 юнит-тестов Rust (IPC, модели, хранилище, пресеты).
